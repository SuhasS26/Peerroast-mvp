# Design System: PeerRoast

## 1. Color Palette
- **Primary / Brand:** `#EA580C` (Warm Flame Orange - action, highlights)
- **Secondary / Slate:** `#475569` (Subtle UI borders, meta indicators)
- **Background:** `#0F172A` (Slate 900 - dark theme body background)
- **Surface / Card:** `#1E293B` (Slate 800 - cards, modals, navigation)
- **Border / Divider:** `#334155` (Slate 700 - structural division)
- **Text Primary:** `#F8FAFC` (Slate 50 - headings, primary text)
- **Text Secondary:** `#94A3B8` (Slate 400 - body, descriptions, timestamps)
- **Accent / Success:** `#10B981` (Emerald 500 - upvotes, status badges)

## 2. Typography
- **Font Family:** `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Headings:**
  - H1: `2.25rem (36px)` / Font Weight: `800` (Extrabold)
  - H2: `1.5rem (24px)` / Font Weight: `700` (Bold)
  - H3: `1.25rem (20px)` / Font Weight: `600` (Semibold)
- **Body:** `1rem (16px)` / Font Weight: `400` (Regular) / Line Height: `1.6`
- **Caption / Meta:** `0.875rem (14px)` / Font Weight: `500` (Medium)

## 3. UI Components Inventory
1. **Navbar:** Fixed navigation header with brand mark, search bar, navigation links, and "Pitch Project" CTA button.
2. **Button:** Primary (solid orange), Secondary (outlined slate), and Upvote variant with dynamic count indicators.
3. **Card:** Modular container with border hover glow, creator badges, and interaction footer.
4. **Badge:** Category and status tags with distinct color coding.
5. **Modal:** Accessible popup dialog for pitching new projects with backdrop blur.
6. **Input & Textarea:** Styled inputs with focus rings and label typography.
7. **EmptyState:** Friendly fallback message with icon when search or filter returns no items.
